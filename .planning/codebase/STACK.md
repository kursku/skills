## Build Pipeline

The build produces `.skill` files (ZIP archives) in `dist/`:

1. `python3 scripts/catalog.py` — Scans all `packs/` directories, parses SKILL.md frontmatter, infers categories, outputs `dist/pack-catalog.json` and `dist/pack-catalog.md`
2. `bash scripts/release.sh` — Builds curated skills (non-pack) into `dist/<category>/<name>.skill`
3. `bash scripts/release.sh --packs all` — Builds all 1,785 pack skills into `dist/<category>/<name>.skill`

Each `.skill` file is a ZIP of the skill folder contents, validated to have `name:` and `description:` in YAML frontmatter.

## Skill Format

A skill is a directory containing at minimum:
- `SKILL.md` — Markdown file with YAML frontmatter (`name:`, `description:`, optional `risk:`, `version:`, `author:`)
- Optional: `scripts/`, `assets/`, `references/`, `agents/`, `examples/` subdirectories
