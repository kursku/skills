# Exemplos Reais ("O Livro de Receitas das Skills para Claude")

Skills sao poderosas sozinhas, mas imparaveis quando combinadas.
Aqui estao tres cenarios comuns e como resolve-los usando este repositorio.

## Receita 1: A "Auditoria de Codigo Legado"

_Cenario: Voce acabou de herdar um repositorio Node.js baguncado de 5 anos atras. Precisa arrumar isso com seguranca._

**Skills Usadas:**

1. `concise-planning` (Para mapear o caos)
2. `lint-and-validate` (Para encontrar os bugs)
3. `security-audit` (Para encontrar as brechas)

**O Workflow:**

1. **Planejar**: "Agente, use `concise-planning` para criar um checklist de refatoracao do `src/legacy-api.js`."
2. **Auditar**: "Rode `security-audit` no `package.json` para encontrar dependencias vulneraveis."
3. **Corrigir**: "Use as regras do `lint-and-validate` para corrigir automaticamente os problemas de formatacao em `src/`."

---

## Receita 2: O "Web App Moderno"

_Cenario: Voce precisa construir uma Landing Page de alta performance em 2 horas._

**Skills Usadas:**

1. `frontend-design` (Para a estetica)
2. `react-patterns` (Para a estrutura)
3. `tailwind-mastery` (Para a velocidade)

**O Workflow:**

1. **Design**: "Use `frontend-design` para gerar uma paleta de cores e tipografia para uma 'Cafeteria Cyberpunk'."
2. **Estruturar**: "Inicialize um projeto Vite. Depois aplique `react-patterns` para criar o componente 'Hero'."
3. **Estilizar**: "Use `tailwind-mastery` para deixar os botoes com efeito glassmorphic e responsivos."

---

## Receita 3: O "Arquiteto de Agentes"

_Cenario: Voce quer construir um agente de IA personalizado que consiga verificar seu proprio codigo._

**Skills Usadas:**

1. `mcp-builder` (Para construir ferramentas)
2. `agent-evaluation` (Para testar confiabilidade)
3. `prompt-engineering` (Para refinar instrucoes)

**O Workflow:**

1. **Construir**: "Use `mcp-builder` para criar uma ferramenta `verify-file`."
2. **Instruir**: "Aplique padroes de `prompt-engineering` no System Prompt para que o agente sempre verifique os caminhos dos arquivos."
3. **Testar**: "Rode `agent-evaluation` para medir com que frequencia o agente falha ao encontrar o arquivo."
