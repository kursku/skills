# Workflow Skills (GSD)

Skills do sistema GSD (Get Stuff Done) para gerenciamento de projetos, milestones e execução de tarefas com AI.

> Estas skills formam um sistema completo. Recomenda-se instalar todas juntas para a melhor experiência.

---

### gsd-new-project
Inicializa um novo projeto com coleta profunda de contexto e criação do PROJECT.md.

[Ver skill](./gsd-new-project/)

---

### gsd-new-milestone
Inicia um novo ciclo de milestone — atualiza PROJECT.md e roteia para requisitos.

[Ver skill](./gsd-new-milestone/)

---

### gsd-plan-phase
Cria plano detalhado de fase (PLAN.md) com loop de verificação.

[Ver skill](./gsd-plan-phase/)

---

### gsd-execute-phase
Executa todos os planos de uma fase com paralelização em ondas.

[Ver skill](./gsd-execute-phase/)

### gsd-verify-work

### gsd-add-phase
